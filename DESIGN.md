# Portfolio design notes

The hero keeps the strong navy/coral/teal direction. The project section is an editorial two-column index on desktop and one clean stream on mobile.

All project art uses the same 16:10 frame on desktop and 4:3 frame on mobile. Every entry owns a base image and a distinct second image which crossfades on hover or keyboard focus. There is no shared selected-project preview.

Content was regrounded from the public `guygir` GitHub profile on 2026-09-17. Only non-fork repositories with a clear project purpose are shown. Forks such as vLLM, llm-d, ZipNN, TextArena, clawdchan, Better-Minimal-WebGL-Template, and BB-Box-Score-analysis are excluded. Empty test repositories are also excluded.

The supported/archive split is still a content judgment: active 2026 sites are shown as supported, while projects without a public live site and older university/Club Tech work are shown in Archive. Guy should edit `status` in `data.js` if his intended maintenance status differs.
