# Guy Girmonsky - Portfolio

A static, responsive portfolio for [Guy Girmonsky](https://github.com/guygir).

## Run locally

Open `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
```

Project data is in `data.js`. The published list intentionally includes only clear, non-fork projects from Guy's public GitHub profile. Every project has two independent image states, with the second shown on hover or keyboard focus.
